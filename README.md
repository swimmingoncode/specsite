# specsite

Publish a repository's Markdown specs (SPEC.md, PLAN.md, amendments, ...) as living pages on a
[Starlight](https://starlight.astro.build) docs site, and as single-file HTML snapshots, from the
same pipeline. The Markdown stays the source of truth; nothing is copied by hand.

Work in progress.
